Agente local

Desconectado

Para dados reais instale o agente FOXYN Monitor (Python) — coleta CPU/GPU/RAM via psutil/GPUtil e serve em ws://localhost:8787. Não cole o código no PowerShell, salve o arquivo.

  1. Baixe monitor.py (+ run.bat) e salve em C:\FOXYN\agent\
  2. No PowerShell nessa pasta: python monitor.py
  3. Se der 'py' não é reconhecido ou 'python' não é reconhecido: reinstale Python marcando Add to PATH ou use winget install Python.Python.3.12, feche/reabra o PowerShell, ou duplo clique em run.bat
  4. Para dados reais: python -m pip install psutil GPUtil websockets depois python monitor.py
  5. Volte aqui e clique em Conectar
